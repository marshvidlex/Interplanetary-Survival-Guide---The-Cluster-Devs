## Estructura

```
docs/       documentación de cada fase
frontend/   aplicación web
backend/    servicios
data/       datos de NASA ya descargados
```

## Cómo trabajamos

- `main` siempre debe funcionar. Nadie sube directo a `main`.
- Cada quien trabaja en su propia rama, por ejemplo `docs/historias` o `feature/mapa`.
- Los cambios entran por pull request y los revisa otra persona del equipo.
